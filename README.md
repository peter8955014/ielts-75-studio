# IELTS 7.5 & Native TV Studio (`ielts-75-studio`)

## 核心功能
- **Part 1 · 聽力精訓（正常 1.0x / 慢速 0.72x 獨立雙欄）**：涵蓋 IELTS Listening Part 1~4 與美劇（*Suits*、*Friends*、*The Office*、*Silicon Valley*）實戰對話，支援美式 (`en-US`) / 英式 (`en-GB`) 口音切換、逐句雙語速跟讀與隨堂測驗。
- **Part 2 · 口說實戰（電腦鍵盤輸入作答）**：完整收錄 IELTS Speaking Part 1~3 題庫與 Part 2 準備/作答倒數計時器；鍵盤輸入回答時即時偵測 Band 7.5+ 高頻詞彙與美劇片語命中率。
- **Part 3 & 4 · 閱讀精讀 & 寫作高分矩陣**：內建 Band 7.5+ 學術長文（點擊高頻字可一鍵收藏）、`True / False / Not Given` 題組，以及 Band 6.0 → 7.5+ 寫作替換矩陣與字數追蹤編輯器。
- **IELTS 7.5 + 美劇高頻單字庫 & 自訂單字本**：動態讀取 `ielts_vocab.json`，標註 `🔥 高頻必考` 與 `🎬 美劇高頻`，支援自訂新增、3D 翻卡複習與 JSON 備份還原。
